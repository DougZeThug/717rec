# Verification: standings

How to run this file: most of these items are read-only and need no account, but
they all need **real league data** — a populated season, at least one bracket, at
least one team with several completed matches, and at least one archived season.
Start signed out in a private window for the visitor items, then sign in as a
player, then as an admin. Several playoff items need a **second browser** signed
in as an admin so a score can be entered while the first browser watches. Between
sections reload rather than navigating, so the five-minute cache is genuinely
empty. Nothing in this file writes anything except the admin items in
`the-playoffs-page.md` and `past-seasons.md` — those write to the **real league**,
so use a test bracket and a test season, never one that matters. Device values:
`visitor`, `player`, `admin`, `browser`, `phone`, `offline`, `slow`,
`second browser`.

Not checkable by hand:

- Whether the automatic season choice is meant to be invisible. Nothing on the
  page explains it and the only sign is the overlap banner; that is a product
  decision, not an observation. See
  [Open questions](../playoffs/the-playoffs-page.md#open-questions-and-verification).
- Whether replacing the list with a bracket is announced to a screen reader. The
  document says it is not; confirming it needs a real screen reader, which is
  outside this file's device list. See
  [`cross-cutting/accessibility.md`](../cross-cutting/accessibility.md).
- Whether the "Loading..." spinner is usually held by the admin check rather than
  the data. Needs request timing, not a look at the screen.
- Whether the page can be put in the state of having no active season *and* no
  season with playoffs active without breaking the live league.
