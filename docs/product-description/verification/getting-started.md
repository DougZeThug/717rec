# Verification: getting started

How to run this file: **every write here is a real write to the real league**, so
use a throwaway email address for every sign-up, a throwaway account for every
join request, and never press Save on a team you do not own. Start each section
signed out in a private window; signing out in one tab signs out the others, so
keep the visitor window separate from the player window. You need four accounts
to finish the file: a **new** address that has never registered, a signed-in
player with a finished profile and no membership, a player with an **approved**
membership, and an admin. `/oauth/consent` cannot be reached without another
application holding a registered client, so the whole `authorize-an-app.md`
section is blocked until the league supplies one — the rows are written so they
can be run the moment it does. Device values: `visitor`, `player`, `admin`,
`browser`, `phone`, `offline`, `slow`, `second browser`.
