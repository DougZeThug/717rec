# Verification: cross-cutting

How to run this file: these five documents describe behaviour that is not on any
one page, so the items move around the app rather than sitting on a route. Set
up more than usual before you start. You need a **desktop browser** with the
network panel and the element inspector open; a **phone**, or a browser at
390 x 844 with touch emulation and the ability to resize past 768 pixels; a
**private window** for the signed-out items; a **player** account with an
approved membership; an **admin** account; a **second browser** for the
two-people items; a way to go **offline** and to throttle to **slow**; and a
real **screen reader** for the accessibility items — the inspector's
accessibility tree answers some of them but never answers "was it announced".

Two limits are worth knowing before you record anything. **The dev server is a
development build**, and several claims here are about what a *published* build
does — analytics, error reporting, and session replay are all switched off
locally. Those items say so, and on a dev server the honest answer is `blocked`.
And the dev server writes to the league's **real database**: the handful of
items here that write anything are marked **(destructive)** and their Steps stop
short of the write wherever the claim can be checked without it.

These documents deliberately drop template sections — the five named phases,
and in three cases the Modifiers table — because a failure, a viewport, an
assistive technology and a recorded pageview are not forms and have no editing
phase. The items below cover what each document does contain; what a dropped
section would have covered is listed under "Not checkable by hand" where it
still matters. Device values: `browser`, `phone`, `visitor`, `player`, `admin`,
`second scorer`, `offline`, `slow`, `second browser`.

  outside the browser.
- Whether `is_admin` is the only column that grants admin anywhere. Needs the
  migrations, not the UI.
- The **Modifiers** table this document drops. Its axis is the user's role,
  which is the subject of every item above; there is nothing left over to check.
