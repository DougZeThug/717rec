# Verification: admin

How to run this file: **read this paragraph before you press anything.** The dev
server carries the app's real public credentials, so it talks to the league's
**real database** — real teams, real seasons, real results, real people's
requests. **Every write in this file is a real write to the real league.** Many
admin actions are destructive and **several have no confirmation at all**: one
press and the row is gone, with no undo, no trash, and sometimes no message.
**Never run a destructive item against a season, team, division, match,
timeslot, request, hero card, or notification that matters.** Every row whose
Claim cell is marked **(destructive)** writes something the app cannot put back.
Where such a row's Steps stop short of pressing the final button, that is
deliberate: the item is *"confirm nothing stands between the press and the point
of no return"*, not *"do the thing"* — read the screen, then Cancel or walk
away. **Several items cannot be run safely at all without a scratch season** — a
season nobody depends on, holding throwaway teams, throwaway matches and
throwaway timeslots. Their Expected cell says so. **If you have no scratch
season, record `blocked` and move on. Do not attempt them on live data to see
what happens.**

With that settled: sign in as an admin, open `/admin`, and work down. The
dashboard remembers the open section **per browser tab**, so a fresh tab starts
at Timeslots and that is how to reach a known starting state — open a new tab
rather than reloading. Several items need a second, non-admin account (`player`)
and a few need two browsers at once. Between sections, reload rather than
switching section, so nothing is left in memory from the section before. Where a
timeslot or a match must be written, use a **date far in the future** that no
league night uses, and remove what you wrote afterwards. Device values:
`admin`, `player`, `visitor`, `browser`, `phone`, `offline`, `slow`,
`second browser`.
