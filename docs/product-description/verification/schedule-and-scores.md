# Verification: schedule and scores

How to run this file: most of the schedule items need nothing but a browser, and
several of the score items need a **match that is more than sixteen hours past
its start time with no result** — without one the Pending Scores card is not on
the home page at all and every `SUBMIT` and `PENDING` item is blocked. Start
signed out in a private window for the visitor items, then sign in as a player
with an **approved** membership, then as an admin. Open `/schedule` in a **new
browser tab** before each `SCHED` tab item, because the chosen tab is kept in
session storage and a reused tab is not a clean start. Remember that the dev
server writes to the real league: report scores only against a throwaway match,
and never press an admin Delete on a match that matters. Device values:
`browser`, `visitor`, `player`, `admin`, `phone`, `offline`, `slow`,
`second browser`.

Not checkable by hand:

- **Whether a match whose team details are missing is silently dropped** from the
  list. It needs a match in the database whose team join is broken, which no
  screen in the app can produce.
- **The "No Time" group and unparsable time labels.** No admin screen can write a
  time the browser cannot parse, so neither the group nor the unpredictable sort
  can be reached.
- **The search-specific empty state.** It exists in the code and is reachable from
  no page, so there is nothing to look at.
- **Whether Thursday is really the league's night.** It is a fixed default with no
  setting behind it; ask the league rather than the app.
