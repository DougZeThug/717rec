# Bump dependency group

## Goal
Update the 22 direct and dev dependencies listed in the request to their target versions, then verify the app still builds and tests pass.

## What will change
- `package.json`: bump versions for the packages in the request table.
- `package-lock.json`: regenerated by `npm install`.
- `bun.lock`: refreshed with `bun install --lockfile-only` so the deploy build stays valid.

## Steps
1. Edit `package.json` with the target versions from the request table.
2. Run `npm install` to update `package-lock.json` and install new versions.
3. Run `bun install --lockfile-only` to keep `bun.lock` in sync for deploy.
4. Run `npm run typecheck` to catch TypeScript/API breaks.
5. Run the fast test gate: `npm run test:coverage` (or `test:coverage:serial` if the parallel run stalls).
6. Run the dependency security scan.
7. Special check: `@lovable.dev/mcp-js` jumps from 2.0.4 to 2.2.0. Inspect the MCP tool files (`src/lib/mcp/tools/_supabase.ts` and `src/lib/mcp/public/tools/_supabase.ts`) for any `JsonValueInput` or API changes and run MCP-related tests if they exist.
8. Report the final result and any manual follow-up needed.

## Risks / watch list
- `@lovable.dev/mcp-js` has needed code fixes on previous bumps; verify its integration.
- `react-router-dom` 7.18.2 → 7.18.4 is a patch bump but touches routing; smoke-test navigation.
- `zod` 4.4.3 → 4.6.5 could affect runtime validation behavior; tests should cover schemas.

## No migrations or source changes expected
This is a dependency-only task unless the typecheck or tests reveal an API change.
